# H!V3MYND bridge

The optional reference bridge: lets agents on other machines read and write notes in your vault, with per-agent tokens and permissions, and shows their activity in the brain.

Setup and protocol: [../docs/BRIDGE.md](../docs/BRIDGE.md). Security notes: [../SECURITY.md](../SECURITY.md).

This bridge never runs commands, opens apps or reads files outside the vault.
